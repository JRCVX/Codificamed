# Interfaz

La interfaz Streamlit se implementa en la Fase 5 (`app/streamlit_app.py`).

Requisitos que cubrirá:

- pegar una nota clínica o cargar un caso ficticio;
- selector de tipo de IA (`local` / `cloud`) con Ollama y modelo Mistral;
- tabla de códigos sugeridos con estado y confianza;
- evidencia resaltada en el texto;
- candidatos recuperados y JSON de salida;
- métricas de latencia y costo;
- descarga de resultados en JSON/CSV.
